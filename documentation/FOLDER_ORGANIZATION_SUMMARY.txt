✨ RECENT FIXES & IMPROVEMENTS (Session 2026-06-18 - v3 Release):

✅ Audio Features (v3):
   • SPL (Sound Pressure Level) display: ~60-90 dB SPL with room calibration
   • Measurement modes: Switch between dB Output (dBFS) and SPL Estimate (Room)
   • Configurable auto-reduce threshold: Adjustable 0-100% for room-specific calibration
   • Auto-volume reduction: Reduces volume by 5% when sustained above threshold for 2 seconds

✅ Code Architecture:
   • Extracted all UI building into modular components (ui/ folder)
   • Created AudioService for audio analyzer management
   • Refactored main.py from 1100+ lines → cleaner orchestrator
   • Improved separation of concerns (services, workers, UI, widgets, dialogs)

✅ UI/UX Refactoring:
   • Moved playback bar creation to ui/playback_bar.py
   • Moved sidebar creation to ui/sidebar.py
   • Moved page creation (download, pitch, extra) to individual modules
   • Created ui/main_layout.py as orchestrator
   • main.py now only handles event connections and app logic

✅ Playback Controls:
   • Added a dedicated Stop button next to Play/Pause
   • Stop freezes the current frame, detaches VLC output, and keeps the image visible on screen

✅ Settings & Configuration:
   • Added "🔊 Audio Settings" section to settings dialog
   • Settings now include: measurement_mode, auto_reduce_threshold
   • Integrated number-type field support in settings dialog
   • Added QComboBox dropdown selector for measurement modes

✅ File Management:
   • Added config/history.json to .gitignore (local user data only)
   • history.json no longer tracked in version control
   • Ensures clean collaborative development

✅ Stability:
   • Pauses audio analyzer during settings dialog to prevent conflicts
   • Properly resumes analyzer after settings close
   • Improved audio service cleanup on application exit
   • No more UI hangs when switching audio modes
   • Recreated audio analyzer threads now reconnect to main dB handler reliably
   • Audio analyzer InputStream now uses compatibility fallbacks (2ch/1ch, 44.1k/48k)
    • Windows meter capture now prefers WASAPI loopback of output device for real playback levels
    • WASAPI output-device discovery is adaptive (host default + output-capable scan), reducing hardware-specific failures
    • Startup fixed for sounddevice 0.5.x by removing unsupported WasapiSettings(loopback=...) usage
    • Windows audio meter now uses soundcard loopback backend first (speaker capture), with sounddevice fallback
    • Sidebar status now refreshes on file load start/success/failure (prevents stale auto-reduce text)
    • Splash progress bar now updates visibly during file preparation and loading stages
   • Task cancellation now waits for worker shutdown (`stop()+wait()`) to prevent QThread-destroyed crashes during conversion/separation
   • Media Loader download actions are now locked during active download/load; repeated clicks no longer spawn overlapping download threads
   • DownloadService now enforces single active `ProcessThread` and rejects concurrent starts to prevent thread-destroyed crashes
   • yt-dlp output parser regexes now use escaped bracket patterns, removing Python FutureWarning spam during downloads
    • Real-time Pitch Mode now has neutral passthrough at 0 semitones, so enabling checkbox no longer alters pitch/tempo unexpectedly
    • Real-time speed updates now sync VLC + shifted stream together (debounced restart), so speed changes continue working while realtime mode is ON
   • Realtime FFmpeg path now uses rubberband for independent pitch and tempo control
    • Hidden live amplification now applies multiplicative gain consistently across repeated adjustments (not just first perceived change)
   • Persistent debug log added at config/app_debug.log (task lifecycle + worker subprocess output)
   • PlayerService auto-configures Windows VLC runtime paths for source runs
     (PATH + VLC_PLUGIN_PATH + add_dll_directory)

✅ Build System (v3):
   • Version bumped to 3 in build.py and spec file
   • INSTALLATION.txt copied to dist/ root for user visibility
